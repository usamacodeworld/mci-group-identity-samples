One system for every platform

Same fonts. Same colors. Same logo family.

All platforms — Medical Consultation, Academy, Career, Research, and the Group — share this system so the brand feels identical everywhere.

01 · Fonts (English + Arabic)

Use these fonts on every platform

Do not invent a different type stack per site. One English pair + one Arabic pair for the whole MCI Group.

English

Better care, shared identity.

Body and UI stay clear for patients, partners, courses, jobs, and research pages.

Headlines: Fraunces Body / UI: Manrope

العربية

رعاية أفضل بهوية واحدة

نفس الخطوط في كل المنصات — استشارة، أكاديمية، وظائف، وأبحاث.

العناوين والنص: Cairo بديل: Tajawal
Rule: English pages use Fraunces (headlines) + Manrope (everything else). Arabic pages use Cairo for both headlines and body. Optional Tajawal only if you need a heavier Arabic UI weight — never mix random Google fonts per platform.
